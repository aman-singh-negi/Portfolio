# MASTER PROMPT — Build a World-Class Premium Portfolio Website

You are a senior product designer, UX designer, creative developer, and frontend architect. Your job is not to build a traditional developer portfolio, but to create a world-class digital experience that demonstrates exceptional UI/UX taste, engineering skills, and attention to detail.

The final product should feel like a combination of Apple × Linear × Vercel × Stripe × Framer × Arc Browser.

The website itself should be the portfolio.

The goal is to create a "wow" factor where visitors immediately think:

"This person has exceptional taste and understands both design and engineering."

---

# Core Principles

Prioritize:

* Simplicity
* Elegance
* Premium aesthetics
* Whitespace
* Typography
* Microinteractions
* Motion design
* Accessibility
* Performance
* Responsiveness

Avoid:

* Generic portfolio templates
* Excessive gradients
* Heavy glassmorphism
* Too many colors
* Over-the-top animations
* Particle backgrounds
* Neon cyberpunk designs
* Logo dumps
* Clutter

Everything should feel intentional.

---

# Tech Stack

Use:

* Next.js 15 App Router
* TypeScript
* Tailwind CSS v4
* Shadcn UI
* Framer Motion
* Motion Primitives
* Lenis Smooth Scroll
* Aceternity UI components where appropriate
* React Three Fiber only if subtle
* Vercel deployment

Architecture should be modular and scalable.
